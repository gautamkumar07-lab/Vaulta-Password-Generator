# 🔐 Vaulta Password Generator

## About The Project

Vaulta Password Generator is a modern and secure web application designed to generate strong, random, and highly secure passwords for personal and professional use. The project helps users create passwords that are difficult to guess and resistant to brute-force attacks, improving overall online security.

The application provides a clean and user-friendly interface where users can customize password length and choose different character types such as uppercase letters, lowercase letters, numbers, and symbols. Based on the selected options, Vaulta instantly generates a strong password using JavaScript logic and browser-based randomization.

A built-in password strength indicator analyzes the generated password and displays whether it is Weak, Medium, or Strong. Users can also copy passwords to the clipboard with a single click, making the tool fast and convenient for daily use.

Vaulta includes a modern Glassmorphism design, responsive layouts, dark/light theme support, smooth animations, and password history management. All generated passwords remain inside the browser, ensuring user privacy and security. No passwords are sent to any external server.

### Features

- Generate secure random passwords
- Adjustable password length (4-50 characters)
- Uppercase character support
- Lowercase character support
- Number support
- Special character support
- Password strength meter
- One-click copy to clipboard
- Password history
- Dark and Light Theme
- Responsive Design
- Modern Glassmorphism UI
- Local Storage Support

### Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Web Crypto API
- Local Storage API
